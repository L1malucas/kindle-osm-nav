# Avisos

## Dados do OpenStreetMap

Os mapas, o grafo de rotas e o índice de busca são gerados a partir de dados do
**OpenStreetMap**, © colaboradores do OpenStreetMap, disponíveis sob a
**Open Database License (ODbL) 1.0**: <https://www.openstreetmap.org/copyright>.

- O código deste repositório é MIT. A licença MIT **não** cobre os dados
  gerados (`build/pack`, `build/data` e o zip da Release), que são uma
  base de dados derivada, sujeita à ODbL.
- Ao redistribuir esses dados, mantenha esta atribuição e a mesma licença.
- Os dados são obtidos em consultas delimitadas à API Overpass (dados brutos).
  Os tiles são renderizados localmente. Nada é baixado de `tile.openstreetmap.org`,
  cuja política proíbe download em massa para uso offline.

## Amazon / Kindle

Projeto independente, **sem afiliação** com a Amazon. "Kindle" é marca
registrada da Amazon.com, Inc. ou de suas afiliadas.

O uso exige jailbreak do aparelho, o que pode violar os termos do fabricante e
traz risco de perda de dados ou de mau funcionamento. Os scripts deste projeto
não alteram o sistema de arquivos raiz e fazem backup antes de registrar o app,
mas você os usa por sua conta e risco.
